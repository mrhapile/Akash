# Agent Context

This portfolio is a motion-led personal developer/design site. The PRD defines the current working agreement, and the rest of the context files should stay aligned with it.

## Stack

React + Vite with GSAP, ScrollTrigger, and Lenis. Use semantic HTML, SVG for decorative graphics, and WebP or AVIF for raster artwork. CSS or Tailwind CSS are both acceptable as long as the implementation stays lightweight and responsive.

## Project Type

Personal portfolio web application.

## Primary Purpose

Showcase selected development and design work through an editorial, Japanese watercolor-inspired experience that feels polished, memorable, and easy to contact from.

## Current Motion Shape

The current experience is a pinned Hero section that hands off into an About parchment sequence and then into a dedicated third-screen video scrub. Keep the motion readable, reversible, and responsive rather than busy.
