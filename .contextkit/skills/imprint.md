# Imprint

Keep the UI consistent across sessions.

## Use when

- Capture a new UI pattern after building a component or page.

## Do

- Compare the new UI against the existing design language.
- Record the pattern that should be reused next time.
- Call out any inconsistencies that need a follow-up fix.

## Avoid

- Letting one-off UI choices become the new default by accident.
- Ignoring spacing, typography, and component shape drift.
