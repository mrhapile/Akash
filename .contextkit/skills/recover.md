# Recover

Diagnose the failure mode and fix it fast.

## Use when

- Something is broken and the first corrective pass did not solve it.

## Do

- Identify whether the problem is a targeted bug, polluted context, or a bad assumption.
- Work from the exact error or failing behavior.
- Choose the smallest correction that breaks the loop.

## Avoid

- Spinning through the same prompt repeatedly.
- Paraphrasing the failure so much that the root cause gets lost.
