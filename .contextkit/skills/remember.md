# Remember

Never lose context between sessions.

## Use when

- Save what happened at the end of a session.
- Restore saved context at the start of a continuing session.

## Do

- Compress the important decisions, progress, and open questions into a compact memory.
- Restore the saved memory before re-explaining the project.
- Keep the summary focused on what the next session needs.

## Avoid

- Repeating the entire working log instead of summarizing it.
- Saving memory so late that the next session starts cold.
